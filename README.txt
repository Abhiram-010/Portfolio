# Abhiram — Cinematic 3D Portfolio

Open `index.html` in a browser.

Included:
- animated star / particle field
- interactive 3D hero portrait using `assets/profile.png`
- custom cursor + magnetic buttons
- scroll-reveal cinematic transitions
- 3D tilt cards
- animated typography
- About Me
- Education
- Certificates
- Skills & technologies
- Projects
- LinkedIn / GitHub / Instagram / Email contact cards
- editable Resume / CV template
- responsive mobile layout

Before publishing, replace:
- social profile URLs
- email address
- education details
- certificates
- project links
- resume content

To deploy, upload the whole folder to GitHub Pages, Netlify, Vercel, or another static host.
